# ChekatLibSite
«ЧЕКАТ» — это современная цифровая платформа и интерактивный веб-хаб, созданный специально для публикации, чтения и обсуждения оригинальных кыргызских веб-комиксов, манхв и вебтунов. Проект объединяет богатое культурное наследие (национальные эпосы, древние петроглифы Саймалуу-Таш) с передовыми тенденциями цифрового искусства и киберпанка.
